## ✨ Features

* **Horological Articulation & Design:** A meticulously crafted SVG sculpture combining deep-sea organic forms with high-end luxury watchmaking aesthetics (inspired by high-complication Swiss dive watches).
* **Dual Finish Modes:**
  * 🟡 **Abyssal Gold:** Warm luxury tones with brushed titanium finishes and rich golden accents.
  * 🔵 **Night Lume:** Deep-sea high-contrast Super-LumiNova luminescence glow mode (`data-finish="lume"`).
* **Precision Escapement Movement:** Toggle between a fluid **28,800 VPH High-Frequency Mechanical Sweep** (8 beats per second) and a classic **1Hz Quartz Step**.
* **Dual Time Display Formats:** Seamless switching between **24H UTC** and **12H Civil** time telemetry.
* **Dynamic Marine Environment:** Animated background caustic light shafts and drifting deep-sea marine micro-particles.
* **Fully Responsive:** Precision telemetry HUD and scaled SVG sculpture optimized for desktop displays, tablets, and smartphones.
